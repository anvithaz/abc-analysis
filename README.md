# ABC Inventory Analysis


Classifies SKUs into A/B/C categories based on revenue contribution using 180 days of sales data.

## Method
- A class: top 70% of revenue
- B class: next 20% of revenue  
- C class: bottom 10% of revenue
## How to Run
```bash
python project2_abc_analysis.py
```
## Tech
- Python 3.12
- pandas
